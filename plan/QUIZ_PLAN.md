# "이 포켓몬은 누구?" 퀴즈 기능 개발 계획

## 1. 목표
포켓몬의 실루엣 이미지를 보고 사용자가 이름을 맞추는 퀴즈 기능을 개발합니다. 이 기능을 통해 사용자에게 재미와 도전적인 경험을 제공합니다.

## 2. 개발 단계 및 순서 (Phase 1)

### 1단계: 퀴즈 페이지 UI 컴포넌트 생성
- **경로:** `src/app/quiz/page.tsx`
- **작업 내용:**
    - 퀴즈 게임을 위한 기본 UI 구조를 생성합니다.
    - 포켓몬 실루엣이 표시될 이미지 영역을 만듭니다.
    - 사용자가 정답을 입력할 수 있는 텍스트 입력 필드와 '제출' 버튼을 추가합니다.
    - 정답/오답 결과 메시지를 표시할 영역을 확보합니다.
    - '다음 문제' 또는 '다시 시작' 버튼을 추가합니다.

### 2단계: 포켓몬 데이터 연동
- **작업 내용:**
    - PokeAPI를 호출하여 퀴즈에 사용할 랜덤 포켓몬 데이터를 가져옵니다.
    - 필요한 데이터는 '포켓몬 이름'과 '스프라이트 이미지 URL'입니다.
    - 1세대부터 9세대까지(1~1025)의 포켓몬 중 하나를 랜덤으로 선택하도록 구현합니다.

### 3단계: 실루엣 이미지 처리
- **작업 내용:**
    - 가져온 포켓몬 스프라이트 이미지에 CSS 필터를 적용하여 실루엣 효과를 만듭니다.
    - `filter: brightness(0)` 속성을 사용하여 이미지를 검은색으로 처리합니다.
    - 정답을 맞췄을 때, 이 필터를 제거하여 원래 이미지를 보여줍니다.

### 4단계: 게임 로직 구현
- **작업 내용:**
    - 사용자가 제출한 답안과 실제 포켓몬 이름을 비교하여 정답 여부를 판별합니다. (대소문자 구분 없이 비교)
    - 정답일 경우: "정답입니다!" 메시지와 함께 포켓몬의 원래 이미지를 보여줍니다.
    - 오답일 경우: "아쉽네요! 정답은 [포켓몬 이름]입니다." 메시지와 함께 원래 이미지를 보여줍니다.
    - '다음 문제' 버튼을 누르면 새로운 랜덤 포켓몬으로 퀴즈가 다시 시작되도록 구현합니다.

### 5단계: 앱에 기능 통합
- **작업 내용:**
    - 메인 헤더 또는 네비게이션 바에 '포켓몬 퀴즈' 페이지로 이동하는 링크를 추가합니다.
    - Next.js 라우터를 사용하여 `/quiz` 경로를 설정합니다.

### 6단계: FSD 구조 리팩토링
- **작업 내용:**
    - `src/app/quiz/page.tsx`에 있던 퀴즈 로직을 `src/widgets/quiz-game/ui/QuizGame.tsx` 위젯으로 분리합니다.
    - 페이지는 위젯을 렌더링하는 역할만 담당하도록 수정하여 FSD 구조를 준수합니다.

## 3. 추가 기능 구현 (Phase 2)

### 1단계: 점수 및 연속 정답 기록
- **작업 내용:**
    - `score`, `streak`, `highScore` 상태 변수를 추가합니다.
    - `localStorage`를 사용하여 최고 점수(`highScore`)를 브라우저에 저장하고, 앱 실행 시 불러옵니다.
    - 정답 시 점수와 연속 정답 횟수를 증가시키고, 오답 시 연속 정답 횟수를 초기화합니다.
    - 현재 점수, 연속 정답, 최고 점수를 화면에 표시합니다.

### 2단계: 시간제한 모드
- **작업 내용:**
    - `timeLeft` 상태 변수와 `TIME_LIMIT` 상수를 추가하여 30초의 제한 시간을 설정합니다.
    - `setInterval`을 사용하여 1초마다 남은 시간을 감소시키고 화면에 표시합니다.
    - 시간이 0이 되면 오답으로 처리하고, 정답을 공개하며 연속 정답 횟수를 초기화합니다.
    - 다음 문제로 넘어갈 때마다 타이머를 초기화합니다.

### 3단계: 힌트 시스템
- **작업 내용:**
    - 포켓몬 데이터 요청 시, 이름과 이미지뿐만 아니라 '타입' 정보도 함께 가져옵니다.
    - `isHintUsed` 상태를 추가하여 힌트 사용 여부를 관리합니다.
    - '힌트' 버튼을 UI에 추가하고, 클릭 시 `isHintUsed` 상태를 변경합니다.
    - 힌트 사용 시, 해당 포켓몬의 타입 정보를 화면에 표시합니다. (`예: 힌트: 이 포켓몬의 타입은 grass / poison 입니다.`)
