### **3D 포켓몬 카드 렌더링 구현 계획**

이 문서는 포켓몬 상세 페이지에 3D 카드 렌더링 기능을 추가하기 위한 개발 계획을 담고 있습니다.

---

#### **1단계: 라이브러리 설치**

3D 렌더링과 HTML 캡처에 필요한 모든 라이브러리를 프로젝트에 설치합니다.

-   `three.js`, `@react-three/fiber`, `@react-three/drei`: 3D 렌더링 및 상호작용을 위함.
-   `html2canvas`: React 컴포넌트(HTML)를 이미지로 변환하여 3D 모델의 텍스처로 사용하기 위함.

#### **2단계: 카드 앞면 컴포넌트 생성 (`PokemonCardFace.tsx`)**

3D로 만들기 전에, 카드에 표시될 2D 콘텐츠부터 만듭니다.
-   새로운 컴포넌트(`src/app/components/PokemonCardFace.tsx`)를 생성합니다.
-   이 컴포넌트는 포켓몬 데이터를 props로 받아, 실제 포켓몬 카드와 유사한 레이아웃(이름, 이미지, 타입, 간단한 스탯 등)을 가진 HTML 구조를 렌더링합니다.
-   처음에는 간단하게 시작하고, 나중에 디자인을 더 정교하게 다듬을 수 있습니다.

#### **3단계: 3D 카드 뷰어 컴포넌트 생성 (`Pokemon3DCard.tsx`)**

3D 렌더링의 핵심입니다.
-   새로운 컴포넌트(`src/app/components/Pokemon3DCard.tsx`)를 생성합니다.
-   이 컴포넌트는 내부적으로 다음 작업을 수행합니다.
    1.  `@react-three/fiber`의 `<Canvas>`를 설정하여 3D 렌더링 공간을 만듭니다.
    2.  2단계에서 만든 `PokemonCardFace` 컴포넌트를 화면에 보이지 않게 렌더링한 후, `html2canvas`를 사용해 이미지 데이터로 변환합니다.
    3.  `three.js`의 `BoxGeometry`를 사용해 얇은 직육면체(카드 모양)를 만듭니다.
    4.  캡처한 카드 앞면 이미지를 이 직육면체의 앞면에 **텍스처(Texture)**로 입힙니다. (뒷면은 일단 단색으로 처리합니다.)
    5.  `@react-three/drei`의 `<OrbitControls>`를 추가하여 사용자가 마우스로 카드를 드래그하여 돌려볼 수 있게 합니다.
    6.  사용자의 마우스 움직임에 따라 카드가 살짝 기울어지며 빛나는 효과(Parallax/Holographic Effect)를 추가하여 입체감을 극대화합니다.

#### **4단계: 상세 페이지에 적용 및 모달(Modal) 구현**

마지막으로, 이 모든 것을 기존 상세 페이지에 통합합니다.
-   `src/app/pokemon/[name]/page.tsx` 파일에 "3D 카드로 보기" 버튼을 추가합니다.
-   이 버튼을 클릭하면, 화면 전체를 덮는 **모달(Modal)** 창이 나타나고, 그 안에 3단계에서 만든 `Pokemon3DCard` 컴포넌트가 렌더링됩니다.
-   모달에는 닫기 버튼이 있어 사용자가 언제든지 카드 보기 모드를 종료하고 상세 페이지로 돌아올 수 있습니다.
